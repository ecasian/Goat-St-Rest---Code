# Goat St Restaurant

Website for Goat St Restaurant - A unique fusion of Mexican and Japanese cuisine located in Radium Hot Springs, BC.

## Features
- Mobile-first responsive design
- Dynamic menu loading from JSON
- Component-based architecture
- Clean, minimalist design

## Structure
- `index.html` - Homepage
- `menu.html` - Menu page with dynamic content
- `components/` - Reusable header and footer
- `css/styles.css` - Main stylesheet
- `include/` - JavaScript files
- `data/menu.json` - Menu data

## Local Development
Simply open `index.html` in a web browser.
